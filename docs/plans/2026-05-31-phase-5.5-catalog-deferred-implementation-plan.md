# Phase 5.5 Catalog Deferred Entities Implementation Plan

> **For agentic workers:** REQUIRED: Use `superpowers:subagent-driven-development` to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking. Each task is one git commit unless a step explicitly says otherwise. Per-task gate cadence (Phase 3+4+4.1+5+5.1 retro lesson): stop after each task's two-stage review (spec-compliance + code-quality) for user disposition.

**Source spec:** `docs/specs/2026-05-31-phase-5.5-catalog-deferred-design.md` (commit SHA: `d375d5ee5`)

**Goal:** Close the 10 entities Phase 5 FD#5 deferred (ProductSupplier, ProductSupplierPreference, ProductPackage, ProductPrice, ProductCatalog, ProductCatalogItem, ProductAttribute, ProductAssociation, ProductComponent, UnitOfMeasureConversion) by extending `services/catalog-service/` to own them; add Category writes per RC-11 breadcrumb; partial RC-13 cleanup (3 of 5 refs deletable without Phase-6 inventory dependency); tag `phase-5.5-catalog-deferred`.

**Architecture:** Extends the existing catalog-service Spring Boot module — no new Gradle subproject. Per-entity migration template: JPA entity → DTO (flat FK-only) → repository → service → controller → Liquibase shadow changelog → nginx route (with Rule 3 exemption when needed) → integration test → conditional Grails-side caller deletion. Cross-service FKs (ProductSupplier→Organization×2, all `User` audit FKs across affected entities) stay at the DTO level as flat string IDs only — no service-side HTTP from catalog to org-service or identity-service per spec FD#2; React handles joins client-side per Phase 5 FD#3 flat-FK pattern. Category writes extension (POST/PUT/DELETE at `/api/category`) per RC-11 breadcrumb. No new cross-service infrastructure (no saga; `services/jwt-auth-common` from Phase 5.1 already wired into catalog-service `build.gradle:14`).

**Tech stack:** Spring Boot 3.3.5 + Java 21 + Hibernate 6 / JPA 3.0 (jakarta.persistence) + Liquibase 4.20+ (shadow changelogs with `tableExists` precondition + empty body) + Spring Data JPA + Spring Security 6 (HMAC HS256 JWT cookie auth via `services/jwt-auth-common` starter from Phase 5.1) + springdoc-openapi 2.5.0 + jjwt 0.12.5 + MariaDB JDBC 3.4.1 + TestContainers 1.21.3 (MariaDB 10) + JUnit 5 + MockMvc; Playwright 1.40+ (chromium; via `e2e/package.json` `npm test`); Gradle multi-module at `services/` (`services/build.gradle` subprojects block); Docker Compose v2; nginx 1.27 reverse proxy at `docker/nginx/conf.d/app.conf` (Rule 3 exact-match-before-prefix convention from `docs/process/plan-ordering-rules.md:32`); GitHub Actions CI at `.github/workflows/e2e-tests.yml` (Playwright) + `.github/workflows/backend-tests.yml` (`./gradlew jacocoTestReport` → runs `test` + `integrationTest` per `build.gradle:891`); Grails 3.3.x legacy monolith at `grails-app/`.
